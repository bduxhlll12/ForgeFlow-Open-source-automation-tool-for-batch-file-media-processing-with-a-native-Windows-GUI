⚡ ForgeFlow

ForgeFlow is a simple open-source tool for automating repetitive file and media processing tasks.
No complicated command-line workflows — everything is controlled through a clean and easy-to-use interface.

✨ Features
* 📁 Batch file processing
* 🎬 Video and image processing
* ⚙️ Preset-based workflows
* 🚀 Parallel task processing
* 📊 Real-time progress tracking
* 🖥️ Clean Windows GUI
* 🔌 Extensible architecture
* 🆓 Fully open source

📦 What's included in v1.0.0

* Drag & Drop support

* Parallel processing
* Settings management
* Operation logs
* Basic processing presets
* Documentation

🚀 Why ForgeFlow?
Most tools require users to deal with complicated commands, configuration files, and dozens of parameters.
ForgeFlow keeps things simple:
Add your files → choose an action → start processing.
The project is designed for both everyday users and developers who want a foundation for their own automation tools.
